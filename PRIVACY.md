# Privacy

`sync-ai` has no telemetry or analytics. It reads the allowlisted Claude Code
or Codex configuration files selected by the user and transfers them only to
the user's configured private Git repository through Git.

The repository provider, Git credentials, and any third-party services used by
the user (such as GitHub) have their own privacy policies. Users should not
sync credentials or private data; the built-in scan is only a safeguard and is
not a guarantee.
